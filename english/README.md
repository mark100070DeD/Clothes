# Кабинет разбора английских ошибок

Одна кнопка «Загрузить отчёт» → список отчётов из базы Notion с датами →
выбираешь отчёт → Claude разбирает каждую ошибку, объясняет правило и даёт
упражнение. Дальше — обычный чат: присылаешь ответы, Claude проверяет.

```
браузер (public/: HTML + CSS + JS)
   │  GET  /api/reports       ──► Notion: запрос к базе
   │  GET  /api/reports/:id   ──► Notion: свойства страницы + все блоки текстом
   │  POST /api/chat          ──► Claude API, ответ идёт потоком
Cloudflare Worker (src/)
```

История каждого разбора хранится в браузере (localStorage) под id отчёта:
вернулся к старому отчёту — разговор на месте, ничего не тратится повторно.
Кнопка «Начать разбор заново» стирает её.

## Что внутри

| Файл | Что делает |
|---|---|
| `src/index.js` | маршруты `/api/*`, пароль, проверка переменных |
| `src/notion.js` | список отчётов, дата отчёта, страница Notion → текст |
| `src/chat.js` | промпт преподавателя, проверка истории, поток от Claude |
| `public/` | фронт без сборки и фреймворков |
| `public/markdown.js` | безопасный мини-Markdown для ответов Claude |
| `test/` | `npm test`, 10 проверок |

## Переменные окружения

Задаются **только в Cloudflare**, в коде их нет — репозиторий публичный.

| Переменная | Обязательна | Что это |
|---|---|---|
| `NOTION_TOKEN` | да | секрет внутренней интеграции: notion.so/profile/integrations |
| `NOTION_DATABASE_ID` | да | 32 символа из ссылки на базу: `notion.so/…/<ВОТ ЭТО>?v=…` |
| `ANTHROPIC_API_KEY` | да | ключ из console.anthropic.com |
| `APP_PASSWORD` | **очень желательно** | пароль на вход. Без него любой, кто узнает адрес `*.workers.dev`, будет разбирать свои ошибки за твой счёт |
| `NOTION_DATE_PROPERTY` | нет | имя свойства с датой отчёта. По умолчанию — первое свойство типа «Дата», а если его нет — время создания страницы |
| `CLAUDE_MODEL` | нет | по умолчанию `claude-opus-5-5` |
| `CLAUDE_EFFORT` | нет | `low` / `medium` / `high`, по умолчанию `medium` |

```bash
cd english
npx wrangler secret put NOTION_TOKEN
npx wrangler secret put NOTION_DATABASE_ID
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put APP_PASSWORD
```

**Не забудь пригласить интеграцию в базу:** в Notion открой базу → `•••` →
Connections → Add connection → твоя интеграция. Без этого Notion отвечает 404,
и кабинет так и напишет.

## Деплой

```bash
cd english
npm install
npx wrangler deploy --keep-vars
```

`--keep-vars` — чтобы деплой не стёр переменные, заданные в панели.

Локально: скопируй `.dev.vars.example` в `.dev.vars`, заполни и запусти
`npx wrangler dev`.

## Как устроен разбор

- Текст отчёта собирается из **свойств страницы** (кроме заголовка) и **всех
  блоков** — заголовков, списков, таблиц, тогглов до 3 уровней вложенности.
  Так что ошибки можно хранить хоть в колонке базы, хоть в теле страницы.
- Отчёт кладётся в системный промпт, а он не меняется от сообщения к
  сообщению, поэтому попадает в кэш промпта: со второго вопроса отчёт стоит
  примерно в десять раз дешевле.
- Ответы Claude идут потоком: текст появляется по мере написания.
- Включён серверный фолбэк (`fallbacks: "default"`): если фильтры безопасности
  по ошибке откажут, запрос молча повторит другая модель.
